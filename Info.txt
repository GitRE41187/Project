System Overview
1. Client (React)

	User สมัคร/ล็อกอิน

	อัปโหลดโค้ด Python (ไฟล์ .py) ของตัวเอง

	จองคิวสนาม

	เมื่อถึงคิว → ปุ่ม Control รถ และ Reset Field จะเปิดใช้งาน

	UI ของ User:

		Upload code

		Queue list

		Control panel (run, stop, reset)

	UI ของ Admin:

		Monitor user, field, คิวปัจจุบัน

		ดู log/ผลลัพธ์จาก Raspberry Pi

2. Backend (Node.js + MySQL)

	Auth (JWT)

	Queue Management (control ว่า user ไหน active อยู่ในคิวตอนนี้)

	File Upload API → เก็บโค้ดของ User ลง DB/Storage

	สื่อสารกับ Raspberry Pi (REST API) เพื่อ:

		Upload code ไปยัง Raspberry Pi

		Run/Stop code

		Reset field (อนุญาตเฉพาะ user ที่ active ในคิว)

	Logging → บันทึกว่าใคร run code อะไร เวลาไหน

3. Database (MySQL)

	Tables หลัก

	USERS (
	  id INT PK,
	  username VARCHAR,
	  password_hash VARCHAR,
	  role ENUM('user','admin')
	);

	BOOKINGS (
	  id INT PK,
	  user_id INT FK -> USERS,
	  field_id INT,
	  start_time DATETIME,
	  end_time DATETIME,
	  status ENUM('pending','active','done','cancel')
	);

	UPLOADS (
	  id INT PK,
	  user_id INT FK -> USERS,
	  file_path VARCHAR,
	  uploaded_at DATETIME
	);

4. Raspberry Pi (Python Flask)

	รับไฟล์โค้ด Python จาก Backend → เก็บเป็น user_id.py

	Endpoint หลัก:

		POST /upload_code → รับไฟล์ .py

		POST /run → รันโค้ดของ user ที่ active

		POST /stop → หยุดโค้ด

		POST /reset → Reset รถไปที่จุด Start (ทำได้เฉพาะ user ในคิว)

	Run script แยก process → ทำให้แต่ละ user run โค้ดของตัวเอง

	Safety: จำกัดสิทธิ์ subprocess, ให้โค้ด import ได้เฉพาะ library ที่อนุญาต

5. Field (สนาม)

	Static field (ไม่ต้อง config เพิ่ม)

	มี Start Point

	ปุ่ม Reset → ส่งสัญญาณไป Pi ให้รถวิ่งกลับ Start

	Reset ใช้ได้เฉพาะ user ที่อยู่ในคิวปัจจุบัน

6. Flow การทำงาน

	Upload

		User อัปโหลดโค้ด Python → Backend → ส่งต่อไป Raspberry Pi → เก็บเป็น user_{id}.py

	Queue

		User จองคิว → Backend จัดลำดับ → DB เก็บเวลาเริ่ม/สิ้นสุด

	Run Session

		เมื่อถึงเวลา → Backend ปลดสิทธิ์ให้ user run code ได้

		User กด “Run” → Backend → Pi → Run โค้ด user_{id}.py

		รถเคลื่อนที่ตาม logic ในไฟล์

	Reset

		User ที่ active สามารถกด Reset → Backend → Pi → รถกลับ Start

	End Session

		เมื่อหมดเวลา → Backend สั่ง Pi หยุด process และ Reset รถอัตโนมัติ

		ปลดสิทธิ์ user → ส่งต่อคิวไปคนถัดไป

7. Tech Stack

	Frontend: React

	Backend: Node.js (Express) + JWT + Multer (upload)

	Database: MySQL

	IoT: Raspberry Pi (Flask + Python subprocess)
