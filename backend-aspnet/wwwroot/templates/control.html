อัปโหลดสคริปต์ Python รันหรือหยุดบนรถที่เลือก และดูสถานะการทำงานแบบเรียลไทม์

อัปโหลดหรือจัดการไฟล์บนรถได้เมื่อมีช่วงจองที่ใช้งานอยู่และได้เลือกรถแล้วเท่านั้น

เคลื่อนที่ (move)

ส่งคำสั่งทิศทางไปรถ (front / back / left / right) — ระยะเวลาเริ่มต้น 0.5 วินาที

ไฟล์บนรถ (สำเร็จรูป + ที่อัปโหลด)

สคริปต์สำเร็จรูปจากเซิร์ฟเวอร์ โฟลเดอร์ static_codes บนรถ และไฟล์ .py ที่อัปโหลด — เลือกรายการแล้วกดรัน (สำเร็จรูปจากเซิร์ฟเวอร์จะอัปโหลดไปรถก่อนรัน)

คอนโซลผลรัน (stdout / stderr)
